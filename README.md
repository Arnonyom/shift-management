# Shift Check-in (GitHub Pages + Supabase)

หน้าเว็บอยู่บน GitHub Pages, ข้อมูลอยู่บน Supabase (ฟรี) → เข้าได้จากทุกที่ ไม่ต้องเปิดเครื่อง NB ไม่มีการถ่ายรูปแล้ว

## ขั้นตอนตั้งค่า (ทำครั้งเดียว ประมาณ 10 นาที)

1. **สร้างโปรเจกต์ Supabase** ที่ https://supabase.com → New project (ตั้งรหัสผ่านฐานข้อมูลแล้วเก็บไว้, เลือก region Singapore)
2. **รัน schema**: เมนู SQL Editor → New query → วางเนื้อหาไฟล์ `schema.sql` ทั้งไฟล์ → Run
   ผลลัพธ์ท้ายสุดจะแสดง **รหัสเชิญ admin** (16 ตัวอักษร) จดไว้
3. **ปิดการยืนยันอีเมล**: Authentication → Sign In / Providers (หรือ Providers → Email) → ปิด **"Confirm email"** → Save
   (ระบบใช้อีเมลภายในที่สร้างจากชื่อผู้ใช้ จึงไม่มีการส่งอีเมลจริง)
4. **ใส่ค่าเชื่อมต่อ**: Project Settings → API (หรือ Data API / API Keys) คัดลอก **Project URL** และ **anon / publishable key**
   แล้วแก้ไฟล์ `config.js`: `SUPABASE_URL`, `SUPABASE_ANON_KEY`
   ⚠ ห้ามใส่ **service_role** key ลงใน GitHub เด็ดขาด (anon key เปิดเผยได้ เพราะสิทธิ์ถูกจำกัดที่ฐานข้อมูลแล้ว)
5. **อัปโหลดขึ้น GitHub**: ใส่ `index.html` และ `config.js` ไว้ที่ root ของ repo `shift-management` (แทนไฟล์ index.html เดิม) → Commit
   Settings → Pages → Deploy from a branch → `main` / `/ (root)`
6. เปิด `https://arnonyom.github.io/shift-management/` → แท็บ **ลงทะเบียนครั้งแรก** → ชื่อผู้ใช้ `admin` + รหัสเชิญจากข้อ 2 + ตั้งรหัสผ่านของคุณ

## การใช้งาน
- หัวหน้า: แท็บ "ทีมและสมาชิก" → เพิ่มสมาชิก → ระบบออก **รหัสเชิญ** ให้ ส่งรหัส (ปุ่ม "ส่งรหัส" คัดลอกข้อความพร้อมลิงก์) สมาชิกลงทะเบียนและตั้งรหัสผ่านเอง
- ลืมรหัสผ่าน: หัวหน้ากด "รีเซ็ตบัญชี" → ได้รหัสเชิญใหม่ → สมาชิกลงทะเบียนใหม่ (ประวัติและตารางกะไม่หาย)
- ทีม 1 (จ–ศ, 4 กะ) และทีม 2 (ศ–จ, 2 กะ) ถูกสร้างไว้ให้แล้ว แก้ได้ในแท็บเดียวกัน; ตารางกะคลิกช่องเพื่อหยุด+ระบุคนแทน
- ตั้งเวลาแจ้งเตือน สาย/ออกก่อน/ไม่มา ในแท็บ "ตั้งค่า"
- เวลา check-in/out ใช้เวลาเซิร์ฟเวอร์ (Asia/Bangkok) และตรวจช่วงเวลาที่ฝั่งฐานข้อมูล แก้จากเครื่องผู้ใช้ไม่ได้

## แก้ปัญหา
- "Supabase ยังเปิด Confirm email": ทำข้อ 3
- "Supabase ไม่ยอมรับอีเมลภายใน": เปลี่ยน `EMAIL_DOMAIN` ใน config.js เป็นโดเมนจริง (เช่น gmail.com) — ใช้เป็นแค่ตัวสร้างชื่อ ไม่มีการส่งอีเมล
- หน้าขาว/ขึ้น "ยังไม่ได้ตั้งค่า": ยังไม่ได้แก้ config.js หรือยัง Commit
- การแจ้งเตือน pop-up/เสียงเกิดเมื่อหัวหน้าเปิดแดชบอร์ดค้างไว้ (ยังไม่ส่ง LINE/อีเมล)
- ฟรีแพลนของ Supabase จะ pause โปรเจกต์ถ้าไม่มีใครใช้งาน 7 วัน (เข้าไปกด Restore ได้)

## ข้อจำกัดที่ยังไม่ได้ทดสอบกับของจริง
ทดสอบ schema บน Postgres จริง (80 รายการ) และหน้าเว็บบน Chromium ด้วยตัวจำลอง Supabase Auth เท่านั้น ส่วน Supabase Auth/PostgREST จริงอาจมีเรื่องจุกจิกตอนรันครั้งแรก ถ้าติดตรงไหนส่งข้อความ error มาได้เลย
